Sobre o Projeto

O Stockfy é um aplicativo mobile desenvolvido como parte de um Trabalho de Conclusão de Curso (TCC) do curso técnico em Desenvolvimento de Sistemas. Ele foi criado com o objetivo de facilitar o controle de vendas, clientes e estoque de pequenos negócios.

Embora tenha nascido como um projeto acadêmico, o Stockfy possui grande potencial de crescimento e está sendo preparado para continuar se desenvolvendo no futuro.

Como instalar o app:

1. Toque no botão acima para iniciar o download.
2. Se aparecer um aviso de segurança, confirme que deseja baixar mesmo assim.
3. Após o download, abra o arquivo APK (geralmente na pasta “Downloads”).
4. Caso apareça uma mensagem bloqueando a instalação, vá em Configurações > Segurança e ative “Permitir de fontes desconhecidas”.
5. Depois disso, a instalação será concluída normalmente.
